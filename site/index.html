Features

Everything the estimate needs. Nothing it doesn't.

01

Real joint geometry, not guesswork

Set root gap, root face, bevel angle, and thickness for square, single-V, and half-V grooves. Unequal member thickness and diameter are supported for pipe-to-pipe and pipe-to-plate joints.

02

A drawing that reinforces the number

Switch between a visual mode for quick review and a technical mode built for engineering sign-off. The section sketch updates live as inputs change, so the geometry and the estimate never drift apart.

03

A report you can actually send

FAQ

Good to know

Does it work offline?

Yes. Every calculation runs on-device. No network connection is required at any point.

Do I need an account?

No. There's no sign-in, no account, and nothing to configure before you can calculate.

What welding processes are supported?

GTAW and SMAW are supported individually, plus a combined GTAW root + SMAW fill split for pipe joints.

Is this a substitute for a WPS or PQR?

No. It's an estimation and planning tool. Formal qualification and compliance documentation still governs the actual weld.

What platforms is it available on?

iOS, with Android and desktop builds on the roadmap. Check back on this page for release updates.
