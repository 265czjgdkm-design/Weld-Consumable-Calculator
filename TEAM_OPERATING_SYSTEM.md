# Team Operating System

## Mission

Turn this application into a trusted welding estimation product that engineers will actually keep on their phone or browser tab.

## Core Roles

### 1. Product Lead

Owns:

- roadmap
- prioritization
- scope control
- premium feature direction

Questions this role asks:

- What should be built next?
- What creates the most trust fastest?
- Which feature is useful versus just impressive?

### 2. Welding Engineering Reviewer

Owns:

- terminology correctness
- geometry credibility
- formula assumptions
- drawing realism
- report language quality

Questions this role asks:

- Would a welding engineer trust this?
- Is the weld metal shown in the correct place?
- Are root face, gap, bevel, and cap described correctly?

### 3. Release and QA Guardian

Owns:

- analyze and test health
- regression control
- bug triage
- release readiness

Questions this role asks:

- What broke?
- What is under-tested?
- Is the UI still understandable after the change?

### 4. Growth and Website Strategist

Owns:

- landing-page quality
- product positioning
- premium conversion logic
- customer-facing clarity

Questions this role asks:

- Would a client understand the value in 30 seconds?
- What makes this feel premium rather than hobby-grade?

## Cadence

### Daily

- review open issues
- verify build health
- identify the highest-value next improvement

### Weekly

- review roadmap
- refine premium opportunities
- evaluate report quality and drawing quality

### Before Every Release

- run analyze
- run widget tests
- run report tests
- build web
- visually inspect estimator and branch module

## Decision Rules

1. Clarity beats novelty.
2. Correct engineering language beats marketing language.
3. Technical drawing must support comprehension, not just aesthetics.
4. 3D is secondary until the 2D explanation is excellent.
5. Premium features must feel useful, not gimmicky.

## Definition of Better

A change is considered good when:

- the estimate is easier to trust
- the geometry is easier to understand
- the report is easier to share
- the interface looks more product-grade
