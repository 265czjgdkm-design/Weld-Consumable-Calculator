## Recommended GitHub Repository Name

`weld-consumable-calculator`

## First Push

```bash
git init
git add .
git commit -m "Initial product system setup"
git branch -M main
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin main
```

## Recommended GitHub Settings

- Default branch: `main`
- Require pull request before merge for future collaborators
- Enable GitHub Actions
- Enable Issues
- Enable Discussions later if customer feedback grows
